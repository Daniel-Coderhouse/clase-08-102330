filter()	Devuelve un nuevo array con los elementos que cumplen una condición	Eliminar productos o filtrar el catálogo
find()	Devuelve el primer elemento que cumple una condición	Buscar si un producto ya está en el carrito
some()	Comprueba si al menos un elemento cumple una condición	// true  o false Saber si un producto está en el carrito
reduce()	Reduce un array a un único valor	Calcular el total del carrito
includes()	Comprueba si un array o string contiene un valor	Buscar productos por nombre
